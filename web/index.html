ps9compatible

Vérificateur de compatibilité PrestaShop 9

Analysez un module ou un thème et découvrez le code qui casse sur PrestaShop 9. Le scan s'exécute entièrement dans votre navigateur — aucun fichier n'est envoyé sur un serveur, tout reste sur votre machine.

  • 100 % local
  • PHP → WebAssembly
  • Aucune installation

Glissez le dossier du module ou du thème, ou un fichier .zip ici

ou

Un ZIP contient normalement un seul dossier portant le nom du module ou du thème. Le type de cible est détecté automatiquement (module ou thème).

Comment ça marche

      
    
        
  • Le module ou le thème est analysé par ps9compatible.php (le même script que le CLI), exécuté dans un
          runtime PHP compilé en WebAssembly chargé dans la page.
    • 
        
  • L'analyse est statique : aucun code du module ou du thème n'est exécuté, les fichiers sont seulement lus
          et découpés en tokens.
    • 
        
  • Les thèmes sont contrôlés comme les modules : présentateurs déplacés, hooks supprimés,
          templates Smarty et pièges de migration (classic → Hummingbird).
    • 
        
  • Aucun envoi réseau : votre module ou votre thème ne quitte jamais votre navigateur.
    • 
      

      

        Un audit statique ne remplace pas un test réel. Testez toujours le module ou le thème sur une copie de votre boutique
        avant de mettre à jour en production.
