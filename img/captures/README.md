# Captures d'écran

Ce dossier regroupe les captures d'écran de l'interface web servant à illustrer le
`README.md`.

## Ajouter une capture

1. Déposez le fichier PNG dans ce dossier, avec un nom explicite et sans espace
   (par exemple `interface-web.png`, `rapport-erreurs.png`).
2. Référencez-le depuis le `README.md` par un **chemin relatif**, par exemple :

```markdown
![Interface web](img/captures/interface-web.png)
```

Aucune autre modification n'est nécessaire : le dossier `img/` est la source de
vérité des images du projet.
